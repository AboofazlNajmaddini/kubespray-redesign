# Kubespray Air-Gap

Ansible-based Kubernetes cluster deployment with full **air-gap (offline)** support. Customized from [Kubespray 2.31.0](https://github.com/kubernetes-sigs/kubespray) for private infrastructure with Nexus registry.

## Stack

| Component | Version | Notes |
|-----------|---------|-------|
| Kubernetes | 1.35.1 | Pinned |
| Cilium | 1.19.3 | CNI, Hubble enabled |
| containerd | Latest | Sole container runtime |
| etcd | Host binary | Non-containerized |
| CoreDNS | 1.13.1 | With NodeLocal DNS Cache |

## Quick Start

### Prerequisites

- Ansible >= 2.14
- Python >= 3.10
- `ansible.posix` collection
- Docker (on the build host only)
- SSH access to all target nodes

```bash
pip install -r requirements.txt
```

### 1. Configure Inventory

Edit `inventory/sample/inventory.ini` to define your nodes:

```ini
[kube_control_plane]
node1 ansible_host=10.0.0.1
node2 ansible_host=10.0.0.2
node3 ansible_host=10.0.0.3

[etcd]
node1
node2
node3

[kube_node]
node1
node2
node3
node4
node5
```

### 2. Build Offline Bundle (on a machine with internet)

```bash
make build
```

This creates `offline/kubespray-offline-bundle.tar.gz` containing all binaries, container images, RPM packages, and Helm charts.

### 3. Transfer to Air-Gapped Target

```bash
scp offline/kubespray-offline-bundle.tar.gz user@target:~/kubespray-2.31.0/
```

### 4. Deploy

```bash
make extract    # Extract the bundle
make deploy     # Deploy the cluster
```

Or in one step:

```bash
make deploy     # Auto-extracts if bundle exists
```

## Makefile Targets

| Target | Command | Description |
|--------|---------|-------------|
| `make build` | `offline-bundle.yml` | Build offline bundle (needs internet) |
| `make deploy` | `cluster.yml` | Deploy cluster (auto-extracts bundle) |
| `make extract` | Extract offline bundle | Unpack tar.gz into `offline/` |
| `make setup-rpm` | `offline-rpm-repo.yml` | Push RPM repo to RHEL nodes |
| `make scale` | `scale.yml` | Add/remove nodes |
| `make reset` | `reset.yml` | Destroy cluster (requires confirmation) |
| `make upgrade` | `upgrade-cluster.yml` | Upgrade cluster versions |
| `make remove-node` | `remove-node.yml` | Remove specific node |
| `make recover` | `recover-control-plane.yml` | Recover control plane |

## Private Registry

All container images are served from a Nexus registry:

| Address | Purpose |
|---------|---------|
| `reg.priv.fabe.ir:5000` | Kubernetes, Cilium, nginx, haproxy images |
| `reg.priv.fabe.ir:5001` | Quay.io proxy (calico, cilium-envoy, etc.) |

Registry config in `inventory/sample/group_vars/all/containerd.yml`:

```yaml
containerd_registries_mirrors:
  - prefix: reg.priv.fabe.ir:5000
    mirrors:
      - host: http://reg.priv.fabe.ir:5000
        capabilities: ["pull", "resolve"]
        skip_verify: true
  - prefix: reg.priv.fabe.ir:5001
    mirrors:
      - host: http://reg.priv.fabe.ir:5001
        capabilities: ["pull", "resolve"]
        skip_verify: true
```

## Offline Download Workflow

The `download_file.yml` role uses **cache-first** logic:

1. If `download_force_cache` is true and file exists in cache -> **skip download**
2. If file is missing -> download from URL, store in cache
3. Sync from cache to all target nodes via `rsync`

This means the deploy phase requires **zero internet access** when the bundle is pre-built.

## Cilium Configuration

Default settings in `inventory/sample/group_vars/k8s_cluster/k8s-net-cilium.yml`:

- **Tunnel**: VXLAN
- **IPAM**: cluster-pool
- **Hubble**: enabled (UI, Relay, metrics)
- **Helm chart**: installed from local path (`offline/charts/cilium-<version>.tgz`)
- **Operator replicas**: 2
- **BPF map dynamic sizing**: enabled

Key Cilium variables:

```yaml
cilium_version: "1.19.3"
cilium_enable_hubble: true
cilium_kube_proxy_replacement: "disabled"
cilium_identity_allocation_mode: "crd"
cilium_install_extra_flags: "--chart-path offline/charts/cilium-{{ cilium_version }}.tgz"
```

## Cluster Specs

```yaml
# Core settings (k8s-cluster.yml)
kube_network_plugin: cilium
container_manager: containerd
etcd_deployment_type: host
kube_proxy_mode: ipvs
dns_mode: coredns
enable_nodelocaldns: true

# Offline defaults (offline.yml)
download_run_once: true
download_localhost: true
download_force_cache: true
download_always_pull: false
```

## What Was Changed from Upstream Kubespray

- **Removed**: flannel, kube-ovn, kube-router, macvlan, multus, calico config, docker runtime, cloud providers
- **Added**: offline bundle pipeline, RPM repo provisioning, cache-first downloads, auto-extraction in cluster.yml
- **Modified**: download role (cache-aware), registry refs (Nexus), Cilium as sole CNI, Makefile with safety confirmations
